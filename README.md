# CodeAlpha Basic Chatbot

A simple rule-based chatbot that responds to predefined messages.

## How to run
1. Open this folder in VS Code.
2. Run `main.py`, or run `python main.py` in the terminal.
3. Type a message and press Enter. Type `bye` to exit.

## Example messages
- `hello`
- `how are you`
- `what is your name`
- `help`
- `bye`

## Features
- Takes messages from the user.
- Responds using predefined rules.
- Continues chatting until the user types `bye`.

## Python concepts
Functions, `while` loop, `if-elif-else`, strings, and input/output.
